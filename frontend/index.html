🇬🇷 About this project

A live simulator of ferry traffic across the Greek islands, built on real ferry schedules, real distances, real weather, and real CO₂ estimates — not simulated data. Ship icons shown when a real sailing is genuinely in progress are positioned using actual elapsed time from the real timetable.
